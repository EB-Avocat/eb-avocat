## Context

The site never states what success is. The audit finds a generic message (A-01) and a CTA whose label promises an appointment while the action is a message form (A-05). No analytics baseline exists, so a redesign could not be judged afterwards.

## Scope

- Define target audiences and priorities: prospects (liberal professionals and entrepreneurs around Lyon), existing clients, networking contacts (QR card), Eva as author.
- Write the positioning in one paragraph: promise, audience, proof, difference (Ordre knowledge, déontologie, anticipating associate conflicts, Lyon). Validate with Eva.
- Choose the primary conversion and its channel: contact request (form, phone, email). Decide whether the CTA stays "Prendre rendez-vous" with a real booking path, or becomes e.g. "Contacter le cabinet" (A-05).
- Define KPIs with a baseline: contact requests per month, phone/email clicks, publication reads, reads that lead to a contact, `/carte` vCard saves, Core Web Vitals.
- Decide how it is measured (reuse existing vendors, privacy-friendly, consent as required by the privacy policy).

## Out of scope

Visual design, copywriting of the pages (see the content issue), implementation of tracking (see the implementation issues).

## Acceptance criteria

- [ ] Positioning paragraph approved by Eva.
- [ ] Audience and journey priorities written (J1-J5 of the audit ranked).
- [ ] Primary CTA and its real action decided (A-05).
- [ ] KPI list with definition, source and a baseline or "unknown, measure from launch".
- [ ] Measurement approach decided, compatible with the privacy policy.
